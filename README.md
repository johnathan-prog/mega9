# SoleScan — סריקת הליכה והתאמת מדרסים אונליין

אפליקציית ווב (mobile-first, עברית RTL) שמעבירה את כל תהליך התאמת המדרסים לאונליין:
שאלון → סריקת הליכה מונחית במצלמת הטלפון → אבחון אוטומטי → המלצת מדרס → תשלום.

## איך זה עובד

1. **שאלון** — בחירה מרובה (אזורי כאב, תזמון, אבחנות, סוגי נעליים).
2. **סריקת הליכה, גובה ברך** — המצלמה עוקבת אחרי המשתמש עם MediaPipe Pose
   ומדריכה בקול ובמסך: "צעד אחורה", "עצור", "לך אל המצלמה", "הסתובב".
   3 מעברים; נדגם ציר הברך (וולגוס/וורוס).
3. **סריקת הליכה, גובה קרסול** — אותו פרוטוקול; נדגמת סטיית גיד אכילס מהאנך.
4. **מבחן קריסת קשת** — עמידה בפרופיל על רגל אחת (לכל רגל): נמדד גובה הקשת
   בבסיס דו־רגלי מול העמסה מלאה; אחוז הקריסה הוא היחס ביניהם.
5. **מנוע אבחון** (`js/engine.js`) — עץ ההחלטה הקליני:
   - גיד אכילס ישר (≤3°) → אין קריסה → ציר ברך בוורוס = **קשת גבוהה**
   - גיד נשבר פנימה >6° או קריסה >37% = **פלטפוס**
   - אחרת = **קשת נמוכה**

   הספים מרוכזים ב־`THRESHOLDS` — זו נקודת הכיול מול אבחון ידני.

## מבנה

- `index.html` — כל המסכים (שאלון, הכנה, סריקה חיה, מידות, תוצאות, תשלום)
- `js/pose.js` — מצלמה + MediaPipe PoseLandmarker + חישובי זוויות
- `js/guide.js` — מכונות המצבים של ההדרכה + הנחיה קולית (עברית, Web Speech)
- `js/engine.js` — סיווג והמלצות
- `js/app.js` — בקר הזרימה

## הרצה

אין build. נדרש שרת סטטי ב־HTTPS (המצלמה לא נפתחת בלי HTTPS):

```bash
npx serve .        # לפיתוח מקומי; בטלפון — דרך https tunnel או פריסה
```

פריסה: Vercel / Netlify / Cloudflare Pages — לגרור את התיקייה, זהו.
לבדיקה אמיתית לפתוח **בטלפון** (Chrome/Safari), באור טוב, עם רגליים חשופות.

## מה עוד לא מחובר (הצעדים הבאים)

- סליקה אמיתית (Grow / Tranzila / Stripe) — כפתור התשלום מדפיס כרגע את
  ה־payload של ההזמנה לקונסול.
- שליחת ההזמנה + פריימים נבחרים לשרת (לוח ניהול למטפל, אימות וכיול ספים).
- מדידת אורך/רוחב ב־AR במקום הזנה ידנית.
- הודעות וואטסאפ/SMS (אישור הזמנה, השלמת סריקה שנעזבה).
